How it works

No sign-up, no API keys to paste. It reads what's already on your machine.

⚙️ Data sources

  • Quota data comes from your existing Claude Code login — the app reads the OAuth token from your local ~/.claude folder and calls the Anthropic usage API.
  • Cost data comes from tokscale, which reads your local agent logs and calculates tokens and cost. It runs via bunx or npx, so you need bun or node for this feature.

🔒 Private by design

  • Everything stays on your computer. No data is stored in the cloud.
  • The only network call is to the Anthropic usage API, using your own login.
  • No account, no telemetry, no tracking.
  • Open source under the MIT license — read the code yourself.

Get Agent Usage
