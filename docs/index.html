Widget & menu bar

Quotas without clicking anything.

On Windows, an optional always-on-top widget floats near your tray with the session and weekly bars. On macOS, the menu bar item shows the same two bars. Plus a one-time system notification when you cross a threshold you set.

  • Always visible, never in the way
  • Configurable warning threshold with native notifications
  • Light and dark themes, launch on startup
Privacy

Your usage data never leaves your machine.

No accounts. No telemetry. No cloud storage. The only network calls are the quota checks to Anthropic, OpenAI, GitHub, Cursor and Google, using the logins you already have, plus the GitHub update check.

Your existing logins

Quota data comes from the tokens Claude Code, Codex, Copilot (editor plugin or gh CLI), Cursor and Gemini CLI already keep on disk. On macOS the Claude token lives in the Keychain, read via the security CLI after one “Always Allow” prompt. Nothing new to sign into, nothing to paste in, nothing leaves the machine.

Download

Up and running in 30 seconds.

One download per platform, no admin rights. Windows updates itself from the tray; macOS shows a Download link when a new version is out.

Windows

Download for Windows

  • Windows 10 / 11 · x64
  • Per-user install, no admin rights
  • Updates itself from the tray
  • Unsigned: SmartScreen shows “Unknown publisher” — choose More info → Run anyway

macOS

Download for macOS

  • macOS 12+ · Apple Silicon & Intel
  • Drag to Applications, lives in the menu bar
  • Shows a Download link when a new version is out
  • Unsigned: Gatekeeper blocks the first launch — open System Settings → Privacy & Security → Open Anyway, or run this in Terminal:
xattr -dr com.apple.quarantine "/Applications/Agent Usage.app"
